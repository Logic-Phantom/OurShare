# 테스트

## 자동 테스트

| 명령 | 범위 |
|---|---|
| `npm test` | 전체 (약 30초) |
| `npm test -- tests/unit` | 도메인·정책 단위 테스트 (빠름) |
| `npm run simulate` | 배정 시뮬레이션과 개발 PC 성능 수치 출력 |
| `npm run typecheck`, `npm run lint` | 타입, 린트. `src/domain` 순수성 규칙 포함 |
| `npm run licenses` | 출시 번들 기준 라이선스 감사, 고지 목록 갱신 |

| 영역 | 파일 | 확인하는 것 |
|---|---|---|
| 배정 엔진 | `tests/unit/allocation/*` | 고정·직접·잠금·완료·지난 날짜 보존, 비율, seed 재현, 다시 배정, 이력 보정, 반복 회피 |
| 시뮬레이션 | `tests/simulation/*` | 일 1~100개·구성원 1~8명 불변 조건, 순수 랜덤 대비 편차, 특정인 쏠림 없음, 계산 시간 |
| 날짜·상태 | `tests/unit/scheduling/*` | 월말·연말·윤년, 주 시작 요일, 완료·건너뛰기·미루기·되돌리기 |
| 통계 | `tests/unit/stats/*` | 배정·완료 부담 분리, 표시 비율 합 100 |
| 알림 규칙 | `tests/unit/reminders/*` | 시간 계산, 대상, 지난 일 제외, 50건 제한 |
| 저장 | `tests/integration/household-storage.test.ts` | 실제 SQLite(Node 내장)에서 스키마, 외래 키, 트랜잭션 롤백, 구성원·비율·집안일 |
| 주간 운영 | `tests/integration/week-plan.test.ts` | 미리보기 무저장, 확정, 중복 거부, 수정 저장, 완료 기록 |
| 백업 | `tests/integration/backup.test.ts` | 왕복, 거부 시 기존 데이터 유지, 형식 검사 |

화면은 자동 테스트가 없고, 웹 미리보기에서 직접 눌러 확인했습니다(README Work Log).

## 실기기 테스트 계획 (미실행)

웹과 네이티브는 SQLite 구현이 다르고, 알림·백업·공유 시트는 웹에서 동작하지 않아 실기기 확인이 필요합니다. 아래 순서대로 진행하고, 결과는 README Work Log에 기기·OS·날짜와 함께 남깁니다.

### 준비

1. [EAS 빌드 목록](https://expo.dev/accounts/lcm2/projects/ourshare/builds)에서 최신 preview APK를 내려받거나 휴대폰에서 바로 설치합니다.
2. PC에서 확인할 때는 USB 디버깅을 켜고 연결합니다: `powershell -File scripts/android-device.ps1 install <APK 경로>` → `launch`.
3. 이름은 시안의 가상 이름(지민, 지은)만 씁니다. 실제 가족 이름이 담긴 캡처를 저장소에 올리지 않습니다.

### A. 기본 흐름

- [ ] 온보딩 3단계 → 홈. 건너뛰기도 한 번 확인
- [ ] 이번 주 배정 만들기 → 다시 배정 → 담당자 직접 변경 → 잠금 → 확정
- [ ] 홈 체크 → 완료 화면 → 되돌리기, 일정 탭 체크
- [ ] 항목 시트: 다른 사람이 했어요, 담당자 바꾸기, 내일로 미루기(일요일 일 포함), 건너뛰기와 취소
- [ ] 일정 수정하기 → 저장. 이번 주 현황, 알림함
- [ ] 앱을 완전히 종료 후 다시 열어 모든 내용 유지

### B. 알림

- [ ] 첫 실행에 알림 권한을 묻지 않음
- [ ] 설정 → 알림 받기 → 권한 승인 → `alarms`로 예약 확인 (14일 안의 일만, 최대 50건)
- [ ] 기본 시간과 "내 차례만/모든 집안일"을 바꾸면 예약이 다시 맞춰짐
- [ ] 실제 수신: 몇 분 뒤 시간으로 집안일을 하나 만들고(30분 전 알림 규칙 주의) 수신 확인, 알림을 눌러 그 날짜의 일정이 열림
- [ ] 완료하면 그 일의 알림이 사라짐, 알림 끄기 → 예약 0건
- [ ] 권한 거부 → 안내 문구와 "휴대폰 설정 열기", 다른 기능은 정상
- [ ] `reboot` 후 예약 유지 (재부팅 복원 권한)
- [ ] 늦게 오거나 안 오는 경우가 있으면 기기·절전 설정과 함께 기록 (정시 전달은 약속하지 않음)

### C. 백업·공유

- [ ] 백업 파일 만들기 → 공유 시트 → 파일로 저장
- [ ] 모든 데이터 삭제 → 온보딩 → 백업 복원 → 개수 확인 대화상자 → 원래 데이터와 같음
- [ ] 다른 JSON이나 사진 파일을 고르면 "우리몫 백업 파일이 아니에요"
- [ ] 이번 주 일정 보내기 → 메시지 앱에 텍스트가 들어감

### D. 접근성·화면

- [ ] `fontscale 2.0`에서 주요 화면이 잘리지 않음 (끝나면 `fontscale 1.0`)
- [ ] TalkBack으로 체크, 요일 칩, 별점, 비율 버튼이 이름과 상태를 읽음
- [ ] 다크 모드, 작은 화면, Android 뒤로가기(온보딩·전체 삭제 후 빈 화면으로 돌아가지 않음)

### E. 권한·출시 빌드

- [ ] `perms`: 요청 권한이 알림·재부팅·진동·화면 깨우기·네트워크 기본뿐이고 푸시·배지 권한이 없음 (D-081)
- [ ] 성능: 구성원 4명, 집안일 20개 이상으로 배정 미리보기와 다시 배정이 1초 안에 끝나는지 체감 확인, 저가 기기면 기기 이름과 함께 기록

### iOS (TestFlight)

위 A~D를 같은 순서로 확인합니다. 알림 권한 팝업, VoiceOver, Dynamic Type, 파일 앱 저장을 추가로 봅니다.
