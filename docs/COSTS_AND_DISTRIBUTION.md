# 비용과 출시 요건

기준일 2026-11-05. 공식 페이지 확인 결과이며 조건은 바뀔 수 있습니다. 링크는 [DECISIONS.md](DECISIONS.md)에 있습니다.

핵심 기능은 로컬 처리와 무료 개발 도구로 추가 서버 비용 없이 구현하도록 설계했습니다. 앱스토어 계정 등록과 이후의 클라우드 공유에는 별도 조건이 있습니다.

## 비용

| 항목 | 비용 | 메모 |
|---|---|---|
| Expo, React Native, SQLite, 알림 | 0원 | 오픈소스 |
| 로컬 Android 개발 빌드 | 0원 | 기존 SDK와 Gradle 환경 사용 |
| EAS Free | $0 | Android 15회, iOS 15회. 대기가 길 수 있고 빌드당 45분 제한. **기존 앱과 같은 계정이면 한도를 함께 쓰는지 확인 필요** |
| Google Play | $25 1회 | 기존 계정이 있으면 추가 없음 |
| Apple Developer | $99/년 | iOS 출시와 TestFlight에 필수 |
| 서버 | 0원 | MVP에 없음 |
| Supabase | 0원, 공유 모드 때만 | Free는 프로젝트 2개, DB 500MB, 활동이 적으면 일시 중지. 2차 자료 기준 수치라 도입 때 재확인. 기존 앱이 이미 슬롯을 쓰는지 확인 |
| 정책 페이지 | 0원 | GitHub Pages |

## 기술 요건 충족 여부

| 요건 | 공식 기준 | 우리몫 |
|---|---|---|
| Play 대상 API | 2026-08-31부터 신규 앱·업데이트 API 36 이상 | SDK 58 대상 36 충족 (빌드 후 확인) |
| Apple 빌드 | Xcode 26, iOS 26 SDK 이상 | SDK 58은 Xcode 26.4+. EAS로 충족 |
| Apple 최소 지원 | iOS 13 이상 | SDK 58은 iOS 16.4+ |
| Android 최소 지원 | 정책 제한 없음 | SDK 58은 Android 7+ |
| 정확한 알람 | 알람·타이머·캘린더 앱에 한해, 정확한 시각이 핵심일 때 | 사용 안 함 |

## 출시 체크리스트

### 소유자만 할 수 있는 일

- [ ] KIPRIS 상표 검색 ([LICENSES.md](LICENSES.md))
- [ ] 아이콘 제작 출처와 상업적 이용 가능 여부 확인
- [ ] 지원 이메일과 개인정보 문의 담당 이름 결정 (`.env.local`, git 제외)
- [ ] `eas init`으로 새 EAS 프로젝트 연결 (또는 Claude가 실행할 수 있게 로그인 상태 확인)
- [ ] GitHub Pages 켜기: Settings → Pages → `main` `/docs`
- [ ] Apple Developer 가입 상태 확인
- [ ] **Play 테스터 12명 × 14일 연속 비공개 테스트** (2023-11-13 이후 만든 개인 계정. 프로덕션 신청 후 심사는 보통 7일 이내). 조직 계정이면 해당 없음. 이미 프로덕션 권한을 받은 계정에서 앱마다 다시 필요한지는 2차 자료가 앱 단위라고 하지만 공식 문구에서 확정하지 못했으므로 Play Console에서 확인

### 구현 후 확인

- [ ] 처리방침 URL 공개: `https://logic-phantom.github.io/OurShare/legal/privacy.html`. 양 스토어와 앱 안에 모두 링크. 수집 데이터가 없어도 필수
- [ ] 약관, 오픈소스 고지 화면
- [ ] 라이선스 감사 통과
- [ ] 병합된 Android 매니페스트 권한 확인
- [ ] iOS 개인정보 매니페스트(Privacy Manifest) 빌드 산출물 확인. 이번 조사에서 최신 요건을 확정하지 못해 제출 전 재확인
- [ ] 아이콘: iOS 1024 정사각·투명 없음, Android 적응형 안전 영역·모노크롬
- [ ] 실기기: 재시작 유지, 알림 승인·거부·재부팅, 복원, 글자 확대, TalkBack, VoiceOver
