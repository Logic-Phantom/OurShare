# 디자인 시스템과 화면 대응표

기준 시안은 [design/reference-screens.webp](design/reference-screens.webp), 아이콘 원본은 `assets/brand/icon-source.webp`입니다. 시안의 레이아웃과 스타일을 그대로 구현하는 것이 목표입니다. 아래 색상값은 시안에서 눈으로 추출한 초기값이며 구현 때 시안과 나란히 비교해 맞춥니다.

## 토큰 (`src/design-system/tokens.ts`)

| 종류 | 값 |
|---|---|
| 배경 | `#FBFAF7`, 카드 `#FFFFFF`, 안내 카드 `#FFF4D6`, 응원 카드 `#FFF7E8` |
| 글자 | 기본 `#2B2B33`, 보조 `#7A7A85` |
| 주 버튼 | `#2F3037` 배경 + 흰 글자, 알약형 |
| 강조 | 초록 `#4CAF50`, 연초록 `#DDF0D4`, 파랑 `#6FA8E8`, 분홍 `#F49A92`, 노랑 `#F6C945` |
| 구성원 색 | 파랑, 분홍, 초록, 노랑, 보라, 청록 (이름과 항상 함께 표시) |
| 간격 | 4, 8, 12, 16, 20, 24, 32 |
| 모서리 | 8, 12, 16, 20, 24, 버튼은 완전 둥글게 |
| 글꼴 | Pretendard: 화면 제목 20 Bold, 섹션 16 Bold, 본문 15 Medium, 보조 13, 큰 숫자 28 Bold |

시안은 라이트 모드만 있습니다. 원문의 다크 모드 요구에 따라 같은 토큰 이름으로 어두운 값을 정의합니다.

## 공용 컴포넌트

`PrimaryButton` `SecondaryButton` `ScreenHeader` `Card` `ChoreRow` `CheckCircle` `WeekStrip` `ProgressRing` `ShareBars` `MemberAvatar` `MemberRow` `WeekdayChips` `SegmentedChoice` `StarRating` `HintCard` `BottomSheet` `EmptyState` `ErrorState` `ConfirmDialog` `InlineMessage`

## 시안 화면 대응 (9개)

| 시안 | 라우트 | 필요한 기능 |
|---|---|---|
| 소개 "이번 주 집안일, 자동으로 공평하게 나눠요." | `onboarding/index` | 3단계 표시, 시작하기 |
| 홈 | `(tabs)/index` | 집 이름 시트, 알림함 아이콘, 주간 링(5/7·71%), 오늘 할 일과 "N개 더", 주간 달력, 안내 카드, 탭 4개 |
| 주간 일정 | `(tabs)/schedule` | 주 이동, 날짜 선택, 체크, 일정 수정하기, 달력 아이콘 |
| 집안일 설정 | `chore/[id]`, `chore/new` | 이름, 반복 요일, 예상 시간, 부담 별점, 고정/자동/수동, 고정 담당자, 저장 |
| 우리집 구성원 | `(tabs)/household` | 구성원 비율, 나 표시, 구성원 추가, 공평하게/비율 지정, 설정 톱니 |
| 이번 주 현황 | `week/status` | 주 이동, 링, 완료·미완료 수, 구성원별 부담 막대, 안내 문구 |
| 완료 | `completed` | 색종이, 일 이름, 확인, 되돌리기 (Reduce Motion 시 정지) |
| 알림 | `notifications` | 기기 내 활동 목록, 시각, 모두 보기 |
| 앱 아이콘 | `assets/brand/` | 스크립트로 규격 변환 |

## 시안에 없어 같은 스타일로 추가할 화면

| 화면 | 이유 |
|---|---|
| 온보딩 집과 구성원, 비율, 집안일 선택 | 시작 후 입력 단계 |
| 집안일 목록 (`집안일` 탭) | 탭 대상이지만 시안 없음 |
| 배정 미리보기 (`week/preview`) | 생성·다시 배정·확정의 핵심 |
| 일정 항목 시트 | 담당자 변경, 잠금, 미루기, 건너뛰기, 대신 완료 |
| 빈 상태: "이번 주 배정 만들기" | 시안은 데이터 있는 상태만 표시 |
| 설정, 백업, 정책, 오픈소스 고지 | 스토어 요건 |

## 그림 자산

시안 이미지에서 잘라 쓰지 않습니다. 해상도가 낮고 다른 요소가 겹쳐 있습니다.

| 자산 | 방법 |
|---|---|
| 앱 아이콘 | 받은 원본을 스크립트로 변환 |
| 진행 링, 체크, 별, 요일 칩, 색종이 | 코드로 그림 (`react-native-svg`) |
| 탭·기능 아이콘 | `@expo/vector-icons` |
| 소개 화면의 집과 사람들, 빗자루, 구성원 아바타 | SVG로 자체 제작 (`Illustrations.tsx`, `MemberAvatar.tsx`). 고해상도 원본을 받으면 교체 가능 |
| 완료 화면의 집, 알림 아이콘 | 단계 3에서 같은 방식으로 제작 |
| 빗자루 외 집안일 그림 | 시안의 컬러 그림 대신 `MaterialCommunityIcons`를 연초록 원 안에 표시 |

## 접근성

- 터치 영역 최소 44pt / 48dp.
- 담당자는 이름, 상태는 아이콘과 글로 함께 표시하고 색만으로 구분하지 않습니다.
- 모든 체크·칩·별점에 스크린리더 레이블을 지정합니다. 예: "분리수거, 지민 담당, 고정, 완료 안 됨".
- 글자 크기 확대에서 잘리지 않아야 합니다. 세로 고정입니다.
