## 앱 이름

| 확인 | 결과 |
|---|---|
| 한국 App Store에서 "우리몫", "OurShare" 검색 (iTunes Search API) | 결과 0건 |
| Play 패키지 `app.ourshare.mobile` | 없음 (404) |
| 웹 검색 | 같은 이름의 집안일 앱은 찾지 못함. 이름이 비슷한 공유 가계부 앱 "우리"가 있음 |
| **KIPRIS 상표 검색** | **미확인. 소유자 확인 필요** |

위 결과는 상표권이 없다는 뜻이 아닙니다. 출시 전 [KIPRIS](https://www.kipris.or.kr)에서 "우리몫", "OurShare"를 9류(앱), 42류(소프트웨어 서비스) 중심으로 검색하세요. "우리" 자체는 일반 단어이지만 금융권 등에 유사 상표가 많을 수 있어 필요하면 변리사에게 확인하는 것이 안전합니다.
